## WMOOP Code of Conduct

WMOOP adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its Code of Conduct, in full. (Maintainers: commit the full Covenant text into this file verbatim at adoption; this header is the project-specific wrapper around it.)

**In short:** we are building a shared description of the whole world, which only works if everyone — of every background — is safe and welcome here. Be respectful, assume good faith, and argue about claims and sources, not about people.

**Scope.** This Code applies in all project spaces (repositories, issues, pull requests, discussions, chat, events) and when an individual is representing the project in public spaces.

**Relationship to other documents.**
- **Conduct** issues (harassment, abuse, discrimination, bad-faith behaviour) are handled here, independently of technical governance.
- **Technical** disputes (how to model something, which taxonomy, whether a source is good enough) are handled under **[GOVERNANCE.md](./GOVERNANCE.md)** §4 and **[ETHICS.md](./ETHICS.md)**.
- The ethical **red lines** in ETHICS.md §3 (e.g. no race-as-human-subclass, no pseudoscience as fact, respectful sex/gender modelling) are substantive content rules; *advocating or repeatedly inserting red-line-violating content in bad faith* is also a conduct matter.

**Reporting.** Report Code-of-Conduct concerns confidentially to the maintainers at **conduct@wmoop.org** *(maintainers: replace with the real contact before launch)*. Reports are handled discreetly and promptly by maintainers who are not involved in the incident.

**Enforcement.** We follow the Contributor Covenant's **Enforcement Guidelines** (Correction → Warning → Temporary Ban → Permanent Ban). Enforcement decisions involving contributor status are ratified by the TSC per GOVERNANCE §4.4, and recorded (with appropriate confidentiality) in the TSC minutes.

**Attribution.** This Code of Conduct is adapted from the Contributor Covenant, version 2.1, available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
